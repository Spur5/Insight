# External Technical Documentation
- Primary UI Framework: daisyUI 5 (Tailwind CSS based)
- Documentation URL: https://daisyui.com/components/

# Instructions for Architect
1. Before suggesting any UI changes or generating a Coder Prompt for frontend tasks, browse the URL above to ensure you are using the latest daisyUI 5 component classes.
2. Prioritize using daisyUI semantic components (e.g., <button class="btn">) over writing custom utility classes where a component already exists.
3. If the website is unreachable, fall back to your internal knowledge of daisyUI 5 but flag this to the user.
